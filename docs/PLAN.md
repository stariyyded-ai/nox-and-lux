# План реализации: «Нокс и Люкс. Маска Баланса»

Цель первого большого этапа — **вертикальный срез**: 10–15 минут игры, по которым видно, какой будет вся игра. В срез входят Корни Великого Древа и Вечная Песнь, битва с Королевой Лесных Теней и побег из её замка. Остальные края делаются только после того, как срез понравится игрокам.

Сроки ниже — ориентир для небольшой команды, которая работает над игрой не каждый день. Главное в плане — порядок этапов, а не даты.

## Этап 1. Прототип движения · 2–3 недели

Самое важное в игре в духе Ori — чтобы просто бегать и прыгать было приятно. Проверяем это до любой графики.

- [x] Бег с разгоном и торможением, прыжок с регулируемой высотой
- [x] «Время койота» и буфер прыжка (прощают неточные нажатия)
- [x] Скольжение по стене, прыжки вверх по стене и отскок от неё (как в Ori)
- [x] **Толчок света**: замедление времени, прицеливание, отталкивание от Люкса и фонарей
- [x] Люкс летает рядом и заряжается на земле или на стене
- [x] Тестовый уровень, точки сохранения, шипы, автотест движения
- [ ] Поддержка геймпада с прицеливанием правым стиком
- [ ] Камера с упреждением по направлению движения
- [ ] «Сочность»: пыль при приземлении, вытягивание и сплющивание спрайта, звуки шагов и прыжка
- [ ] Подбор чисел вместе с игроками: дать 5 людям поиграть по 10 минут

**Готово, когда:** люди без подсказок проходят тестовый уровень и хотят пройти его ещё раз.

## Этап 2. Арт-направление · 3–4 недели, параллельно с этапами 1 и 3

- [ ] Листы персонажей Нокса (баку) и Люкса (цилинь), пять состояний маски Нокса
- [ ] Цветовой ключ-кадр Вечной Песни
- [ ] Решение по анимации: скелетная (Skeleton2D в Godot или Spine) или покадровая. Для небольшой команды советуем скелетную: дешевле и плавнее, как в Ori
- [ ] Один экран Вечной Песни в финальном стиле: 4–5 слоёв параллакса, свечение, частицы
- [ ] Шрифт и стиль интерфейса (рамки в духе Билибина)
- [ ] Включить Git LFS для крупных файлов арта и звука

**Готово, когда:** один экран в игре выглядит как кадр из будущего трейлера.

## Этап 3. Бой и враги · 2–3 недели

- [ ] Теневой удар (ближняя атака) и Теневой луч (дальняя, за энергию)
- [ ] Ячейки жизни и энергии, получение урона, неуязвимость после удара
- [ ] Отражение снарядов Толчком света
- [ ] Враги Вечной Песни: лешачата, волколаки, нетопыри-мары, мандрагоры
- [ ] Мини-босс: вожак волколаков Клык

## Этап 4. Системы мира · 2–3 недели

- [ ] Комнаты и переходы между ними, загрузка зон
- [ ] Сохранение: Искра Люкса (за энергию) и Родники Древа (бесплатно)
- [ ] Карта мира, карты от Нипа
- [ ] Роса Великого Древа и дерево умений (ветки Тьма, Свет, Баланс)
- [ ] Двери и препятствия, открываемые умениями (основа метроидвании)
- [ ] Диалоги и простые задания

## Этап 5. Вертикальный срез · 6–8 недель

- [ ] Немой пролог: ужин на Древе, ссора, раскол маски
- [ ] Корни Великого Древа: обучение
- [ ] Вечная Песнь: три яруса леса, деревня в кронах
- [ ] Жители: Дубомир, Нип, Колючка, птенец Уголёк; задания «Потерянные жёлуди» и «Песня для Вечной Песни»
- [ ] Лист-парашют как награда края
- [ ] Босс: Королева Лесных Теней (сирин), три фазы
- [ ] Побег из рушащегося замка
- [ ] Музыка: темы Нокса и Люкса, тема леса; звуки
- [ ] Меню, настройки, пауза

## Этап 6. Плейтест и публикация среза · 2–3 недели

- [ ] Закрытый плейтест на 10–20 человек, сбор отзывов
- [ ] Исправления и полировка
- [ ] Сборки для Windows, macOS и Linux
- [ ] Страница на itch.io, короткий ролик и скриншоты

## Дальше

После среза края делаются по одному, каждый по той же схеме: уровень → жители и задания → враги → босс → побег. Порядок: Небесные Кроны, Звонкая Круча, Шепчущая Топь, Пепельная деревня, Ледяные гроты, Пустошь Хаоса и финал.

## Команда

| Роль | Что делает |

| Геймдизайнер и продюсер | Дизайн-документ, уровни, задания, приоритеты |
| Программист | Godot, механики, системы мира |

| Аниматор | Анимации персонажей и боссов (может совмещать художник) |
| Композитор и звукорежиссёр | Музыка и звуки, можно привлечь ближе к этапу 5 |

## Инструменты

- **Движок:** Godot 4.3 (бесплатный, хорошо подходит для 2D)
- **Графика:** Krita или Photoshop для фонов, Aseprite при пиксельном стиле
- **Анимация:** Skeleton2D в Godot или Spine
- **Звук:** Audacity, Reaper; музыка — в любой DAW
- **Задачи:** GitHub Issues и GitHub Projects
- **Хранение:** Git, для арта и звука — Git LFS

## Главные риски

| Риск | Что делаем |
|---|---|
| Объём: метроидвания с восемью зонами — очень большая игра | Сначала только срез; остальное решаем после плейтеста |
| Рисованная графика в духе Ori дорогая | Рано проверяем стиль на одном экране и считаем стоимость одного края |
| Движение «не ощущается» | Этап 1 не заканчиваем, пока игрокам не станет весело |
